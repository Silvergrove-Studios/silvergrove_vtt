# Third-party components and formats

| Component | Use | Licence |
|---|---|---|
| Godot Engine 4.7 (incl. thorvg SVG rasteriser, zlib, libwebp, libjpeg-turbo) | runtime | MIT (bundled libs: permissive) |
| PDF 1.5 (ISO 32000-1) | written by `hexmap/io/pdf_writer.gd` | open specification, freely implementable |
| Universal VTT v1 (`.dd2vtt`) | written | de facto open format introduced by Dungeondraft; no licence claim on the format |
| Foundry VTT scene schema | written (documents only; no Foundry code) | schema of a proprietary product, documents are user data |
| Tiled JSON map format (`.tmj`) | written | open specification (Tiled is GPL/BSD; the format is documented for any use) |
| UVTT v2 draft | reference only | Apache-2.0 |
| [godot-dockable-container](https://github.com/gilzoide/godot-dockable-container) (`addons/dockable_container`) | dock/tab panel layout | CC0-1.0. Local patch: `layout_split.gd` `get_names()` copies the first leaf's array before appending (packed arrays are by-reference in Godot 4; the original mutated the layout on every read). |
| [Lucide](https://lucide.dev) icons (`hexmap/ui/icons`) | UI glyphs, rasterised at run time | ISC |
| [Inter](https://rsms.me/inter/) (`hexmap/ui/fonts`) | UI font | SIL OFL 1.1 |
| [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (`hexmap/ui/fonts`) | coordinate readout | SIL OFL 1.1 |

Placeholder art in `packs/` is generated by `tools/gen_pack_art.gd` and is
owned by Silvergrove Studios.
