# Content packs

A pack is a directory with a `pack.json` manifest and the images it names.
The three packs under `packs/` are examples with generated placeholder art;
real packs will be their own repositories, dropped into any of the pack
search paths (`packs/` in the project, `user://packs/`, and any directory
listed in the editor's Preferences → Pack folders).

Packs are loaded at run time with `Image.load_from_file` /
`Image.load_svg_from_buffer`, not through Godot's import pipeline, so a pack
needs no `.import` files and no Godot at all to author. PNG, JPEG, WebP and
SVG are accepted. SVG is rasterised at the density the map is rendered at,
so it is the right choice for anything that must print sharp.

## pack.json

```json
{
  "format": "silvergrove.pack",
  "version": 1,
  "id": "woodland",
  "name": "Woodland",
  "pack_version": "0.1.0",
  "authors": ["Silvergrove Studios"],
  "license": "Proprietary — internal use",
  "description": "Temperate forest floors, trees, camps and clearings.",
  "terrains": [ … ],
  "props": [ … ],
  "walls": [ … ],
  "lights": [ … ]
}
```

`id` is the namespace every asset in the pack is referenced by
(`woodland:oak_large`). Lower-case, underscores, unique across the packs a
map uses. `pack_version` is recorded by maps that use the pack.

### Terrain

```json
{ "id": "grass", "name": "Grass", "color": "#5b8c3a",
  "textures": ["terrain/grass_1.svg", "terrain/grass_2.svg", "terrain/grass_3.svg"],
  "fit": "hex", "tags": ["ground", "open"] }
```

- `textures`: one or more variants. The editor cycles variants on repeated
  clicks and randomises them for fills.
- `fit`: `hex` — the image is a hexagon that exactly fills the cell's bounding
  box (pointy-top for pointy maps; the loader rotates for flat maps).
  `square` — a seamless square texture; the cell is cut out of it in place,
  so neighbouring cells of the same terrain tile continuously.
- `color`: used for the palette swatch, for the minimap, and as the fill when
  the texture is missing.

### Prop

```json
{ "id": "oak_large", "name": "Large oak", "texture": "props/oak_large.svg",
  "size": [2.2, 2.2], "anchor": [0.5, 0.55], "layer": "overhead",
  "blocks": { "move": true, "sight": false }, "height": 3.0,
  "light": null, "tags": ["tree"] }
```

- `size`: drawn width and height in hex units at scale 1.
- `anchor`: the point of the image (0–1 in each axis) placed at the prop's
  `pos`. For a tree, the trunk; for furniture, the middle of its footprint.
- `layer`: default drawing layer (`ground`, `objects`, `overhead`); the map
  can override per instance.
- `blocks`: what placing this prop implies for exporters that want to
  generate walls from props (not done by default; recorded for tooling).
- `height`: default height in hex units.
- `light`: an optional emitter, same shape as a map light without `pos`
  (a campfire prop that carries its own light). Placing the prop offers to
  place the light.

### Wall style

```json
{ "id": "stone_wall", "name": "Stone wall", "texture": "walls/stone_wall.svg",
  "width": 0.12, "color": "#8a8578",
  "preset": "wall" }
```

`preset` picks the default semantics when drawing with this style (see
`map-format.md`, wall presets). `texture` is optional: a tiling strip drawn
along the wall; without it the wall is a coloured line of `width` hex units.

### Light preset

```json
{ "id": "torch", "name": "Torch", "bright": 1.5, "dim": 3.0,
  "color": "#ffa040", "intensity": 1.0, "animation": "torch" }
```

## Placeholder art

Everything under `packs/*/` was generated by `tools/gen_pack_art.gd` and is
deliberately plain: flat colours and simple shapes so it reads as
"placeholder" at a glance. Replace files in place; the manifests need not
change if the filenames do not.
